02 / BEHAVIOR

Boundaries made explicit

Policy and nested output

Shared typed traversal handles structs, lists, maps, literal dotted names and container dependencies. Ancestor masks, NULL structs and hidden map keys cannot diverge between preview, schema and execution.

Tickets and resources

Every task validates before atomic issuance. Captured principal and policy govern fetches; each emitted batch checks expiry, deadline and revocation. ManagedStream closes unstarted and active resources once and preserves primary errors.

Sources and Arrow

One opened format/schema descriptor per planning operation. Passive JSON captures pinned Iceberg data/delete files, partition values and residuals. Duplicate JSON fields, oversized schemas and ambiguous Arrow names fail closed. Projection ordering fixed for Java/Spark; matching Arrow buffers stay shared.

Control and UI

Source discovery shares the admitted lifecycle and bounded operation-scoped pagination. Workspace summary aggregates in SQL; revision conflicts carry typed values. Draft/save fences preserve edits during requests, query caches isolate sessions, and navigation owns unsaved-change guards.

05 / RELEASE BOUNDARY

Coordinated cutover, documented limits

Preserved

Catalogs, assets, policy revisions/rules, owners and audit remain through migration. HTTP and Flight stay v1; supported Python, DuckDB, Polars, Java and Spark 3 behavior remains.

Breaking

Internal imports move. SDK/package 0.2 uses plugin API 2 and v2 entry-point groups. Rebuild plugins and exact lock, stop both planes, migrate, restart. Outstanding executable tickets are invalidated; clients re-plan.

Limits retained

  • No distributed aggregate memory/admission controller or cluster capacity claim.
  • Blocked provider IO cannot always be interrupted by deadline checks.
  • Planning grows with file count; associated deletes have no hard aggregate byte cap.
  • Arrow budgets reject oversized batches after allocation; they are not a process RSS cap.
  • Per-batch database revocation needs deployment-concurrency sizing.
  • Spark 4, distributed retry/speculation and unsupported type cells remain outside the verified matrix.
