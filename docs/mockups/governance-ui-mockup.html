Design rules for wide and deep schemas: never render a full inventory; group coverage by subtree instead of raw counts; aggregate mask state at parent nodes and resolve values only where you point; and bulk-apply from the subtree so operators never enumerate 1,204 fields.

Correction from the previous revision. An earlier draft framed "granted but unmasked" as a disclosure hole and used danger styling for it. That was wrong: resolve_access intersects each grant with the reader's requested path (_matching_columns), so a parent grant narrows to the requested leaf and never spills to siblings. The kernel prevents the failure. What remains is a completeness question — did the operator configure a mask for everything they meant to? — which is why this is now neutral/amber rather than red.

Other defects this mockup does not draw — code-verified

Sign out drops unsaved edits

Workspace.tsx:328 calls logout() with no confirm. invalidate() clears the cache and remounts children via key={generation}. The beforeunload guard does not apply.

Fix: run confirmDiscardUnsaved() first — reuse the navigation guard.

Save blocked, cause hidden

Collapsing a rule leaves pending set, so Save is disabled while the only explanation sits inside the collapsed card.

Fix: show the pending count on the collapsed rule header and focus it.

Row filter dropped silently

"All rows" commits onChange(null) immediately, widening the audience with no confirmation and no undo.

Fix: confirm when discarding a non-empty filter.

Two test entry points

"Test Policy" and "Test saved policy" open the same modal; only the modal body reveals it evaluates the saved revision.

Fix: one control, one label.

Activity refetch looks idle

loading is ignored once data exists, so applying filters leaves the old list with no busy signal.

Fix: aria-busy plus an "Updating activity…" status.

Picker rows are all tabbable

Options use tabIndex={0} while the input drives aria-activedescendant — Tab walks every row. At 10k fields that is a trap.

Fix: roving tabindex, tabIndex={-1} on rows.

Validate-on-keystroke shouting

Settings validates provider fields per keystroke through role="alert"; clearing a field to retype fires "Issuer URL is required."

Fix: validate on blur and submit.

Focus starts off-screen

Workspace.tsx:136-139 focuses the hidden mobile-nav trigger on first paint.

Fix: skip on mount.

Token field invites password storage

LoginPanel.tsx:66-73 uses autoComplete="current-password" for the control-plane token.

Fix: autoComplete="off" / "one-time-code".
