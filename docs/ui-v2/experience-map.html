04 / Trust

No ambiguity between
saved and active.

UnsavedSaved draftValidated revisionReviewedPublished

Autosave never publishes. Review binds to the exact revision and current generation. A timeout gets an “outcome unknown” state until the server reconciles it.

The review explains generation-wide ticket invalidation, tested personas, and any impact that could not be determined.

Security belongs in the workflow

  • Server checks every action and resource.
  • Admin access does not grant source-row access.
  • Preview uses synthetic fixtures by default.
  • Conflicts preserve edits; no silent overwrite.
  • History restores into a new validated draft.
  • Secrets stay outside the browser and telemetry.

Every package needs evidence. A screenshot or mocked success state cannot complete it. Gateway capability gaps remain explicit dependencies.
06 / Release bar

Measure understanding.
Prove safe completion.

USABILITY TARGET

4 of 5 users

Complete each core task without help. Zero critical misunderstanding of access or publication scope.

ACCESSIBILITY TARGET

WCAG 2.2 AA

Manual keyboard and screen-reader sessions, 200% zoom, visible focus, understandable errors, and responsive workflows.

PERFORMANCE TARGET

Responsive under load

10,000 assets, 5,000 schema fields, depth 12, and 100 rules. Under 100ms p95 local edit feedback on the reference device.

Targets are proposed and unmeasured. Full API, preview, initial-view, and memory budgets appear in the specification.

Required failure scenarios

Expired session, unauthorized metadata, invalid mask, nested projection conflict, stale test result, schema drift, concurrent edit, duplicate publish, timeout after commit, and unavailable catalog/database.

What stays outside this release

Extra backends, arbitrary SQL workbenches, approval automation, live collaboration cursors, IdP management, AI policy generation, and multi-tenant self-service.
