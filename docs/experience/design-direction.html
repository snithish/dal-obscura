05

A stable local URL, with real SSO

Browser → HTTPS hostname → Access → named tunnel → local HTTPS proxy

Existing application OIDC, session and policy checks remain authoritative.

Quick Tunnels remain disposable previews. The full local profile uses a stable hostname and a deliberate Access policy. Offline HTTPS/OIDC remains available without Cloudflare.

Arrow Flight → separate local/private TLS endpoint

Public-hostname Cloudflare Tunnel does not support gRPC. Do not advertise the web URL as a Flight endpoint.
