This is the measured N01 baseline for candidate `a04ce7a` plus the completed

## Supported toolchain policy

The supported application toolchain is Python 3.12, Node.js 24, pnpm 12.3.4,
Java 17, and PostgreSQL 16.4. CI and the production UI image use these versions
(`.github/workflows/ci.yml` and `ui/Dockerfile`). The local host used for this
baseline is Python 3.12.10, Node 26.8.2, pnpm 12.4.1, Java 17.0.20.1 and Maven
3.9.16; Node 26 and pnpm 12.4.1 are recorded as host tooling only and are not
support claims. The application package keeps its historical `>=3.10` metadata
until the contract/package split in N02; only Python 3.12 has a CI support claim
and this is stated in `docs/compatibility.md`.

Resolved runtime libraries in the locked environment are FastAPI 0.136.1,
SQLAlchemy 2.0.48, PyArrow 23.0.1, DuckDB 1.5.0, PyIceberg 0.11.1 and Polars
1.44.2. The UI lock resolves React/ReactDOM 19.2.7, Vite 7.3.6,
`@vitejs/plugin-react` 5.2.0 and TypeScript 5.9.3. No prerelease dependency or
unbounded image tag was introduced by this baseline slice. Vite/React remain
the current tested lines; their planned upgrades are separate work and require
clean-install evidence before changing the pins.

## Boundary and documentation decisions

- The service remains stateless at the data plane; durable control-plane state
  stays in the existing database.
- Pickle serializers, serialized classes/import paths and payload semantics are
  protected and were not modified by this baseline slice.
- The normal operator path is the authenticated control-plane UI. CLI commands
  remain for migration, bootstrap/maintenance and offline validation; they do
  not create a second policy authority.
- Local mode uses the same authorization and CSRF/session checks as production;
  its disposable bootstrap token is development-only and must be closed before
  readiness.

Open qualification remains tracked in `STATUS.md`: N02–N16, live OIDC/browser
evidence, PostgreSQL two-process races, real catalog and Spark/consumer cells,
capacity/recovery drills, artifact integrity and independent security/UX review.
